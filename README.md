## 🚀 Featured Project

### 📉 Customer Retention Intelligence Platform

<div align="center">
  <a href="https://github.com/Amith-appi-85/customer-retention-intelligence-platform">
    <img src="https://github-readme-stats.vercel.app/api/pin/?username=Amith-appi-85&repo=customer-retention-intelligence-platform&theme=nord&border_color=a78bfa&title_color=a78bfa&icon_color=a78bfa&text_color=e5e9f0" alt="Customer Retention Intelligence Platform" />
  </a>
</div>

End-to-end ML platform that predicts customer churn on the IBM Telco dataset (7,043 records, 33 features), reaching **85.3% ROC-AUC** and **79.3% accuracy**. SHAP explainability surfaces key churn drivers (contract type, tenure, monthly charges) and turns them into business recommendations, alongside customer segmentation and revenue-at-risk models, all served through a 9-module Streamlit dashboard.

| Layer | Technology |
| :--- | :--- |
| Language | Python |
| Data Processing | Pandas, NumPy |
| Modeling | XGBoost, Scikit-learn |
| Explainability | SHAP |
| Dashboard | Streamlit, Plotly |
| Dataset | IBM Telco Customer Churn |
